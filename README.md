# claude-mods

Claude Code 用のモッズ（hooks モジュールのプラグイン）集です。

## irai-checklist — 依頼チェックリスト

長いセッションで、途中で頼んだことが黙って抜け落ちるのを防ぎます。

- **横のパネル**：そのセッションで出した依頼を、未着手／対応中／確認待ち／完了／取り下げ で色分けして並べます。各行の「完了にする」「取り下げ」「戻す」ボタンで自分でも状態を変えられます。小さく畳むと件数だけの表示になります。
- **Claude が自分で登録**：メッセージを受け取ると、Claude は作業を始める前にその中の依頼を1件ずつ登録し（まとめて頼まれたものは分けて）、進み具合に合わせて状態を更新します。
- **取りこぼし防止**：最新のメッセージが登録されていないとき、または未着手・対応中の依頼が残っているとき、Claude が作業を終えようとすると一度だけ止めて、対応するよう指示します。返事待ちなら「確認待ち」、不要なら「取り下げ」にして理由を書けば終えられます。
- **ステータスライン**：画面下に「依頼 未完了2件・確認待ち1件」のように表示します。
- **`/irai`**：パネルを閉じたときにもう一度開きます。

チェックリストはセッションごとに空から始まります。雑談だけのメッセージでも、Claude は「依頼なし」と記録するために一度ツールを呼びます。

## インストール

ターミナルの Claude Code のプロンプトで：

```
/plugin install irai-checklist --marketplace COMPASS-4779/claude-mods
```

`Add marketplace?` に `y` と答え、インストール先のスコープを選びます。

シェルから：

```
claude plugin install irai-checklist --marketplace COMPASS-4779/claude-mods
```

デスクトップアプリ（`/plugin` が使えない場合）：プロンプト欄の横の + → Plugins → Add marketplace に `COMPASS-4779/claude-mods` を入力 → Add plugin。
